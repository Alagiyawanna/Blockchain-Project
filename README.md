# 🛡️ ThreatChain — Decentralized Cyber Threat Intelligence & Malware Hash Registry

## 📋 Project Overview

ThreatChain is a blockchain-powered **Indicator of Compromise (IoC) registry** that solves critical vulnerabilities in centralized Cyber Threat Intelligence (CTI) databases like VirusTotal or MISP:

| Problem | ThreatChain Solution |
|---|---|
| **Single Point of Compromise** — attacker hacks the server and deletes their malware hashes | **No single server** — data lives on a decentralized, immutable blockchain |
| **Auditability & Trust** — no proof of who reported what, or when | **Cryptographic signatures** — every IoC is signed by the reporter's Ethereum private key with an immutable timestamp |
| **Retroactive Modification** — threat logs can be silently edited | **Immutable ledger** — once registered, a threat record can never be altered |

## 🏗️ Architecture

```
┌──────────────────────────────────────────────────────────────┐
│                    SOC ANALYST (Web Dashboard)               │
│  • Drag-and-drop file → SHA-256 computed in-browser          │
│  • Submit IoC to blockchain via MetaMask / direct RPC        │
│  • Search hashes, view live feed, manage analysts            │
└──────────────────────┬───────────────────────────────────────┘
                       │ Signs & sends transaction
                       ▼
┌──────────────────────────────────────────────────────────────┐
│              BLOCKCHAIN (Hardhat Local / Sepolia)             │
│  ┌────────────────────────────────────────────────────┐      │
│  │           ThreatRegistry Smart Contract            │      │
│  │  • mapping(bytes32 → ThreatIoC) — O(1) lookup     │      │
│  │  • AccessControl: Only ANALYST_ROLE can register   │      │
│  │  • Events: ThreatReported, ThreatRevoked           │      │
│  │  • Immutable audit trail with timestamps           │      │
│  └────────────────────────────────────────────────────┘      │
└──────────────────────┬───────────────────────────────────────┘
                       │ Queried via Web3.py (JSON-RPC)
                       ▼
┌──────────────────────────────────────────────────────────────┐
│               EDGE DEFENSE AGENT (Python)                    │
│  • Monitors directories using watchdog                       │
│  • Computes SHA-256 of new/modified files                    │
│  • Queries blockchain: isThreat(hash)?                       │
│  • If MATCH → quarantine file + incident report              │
└──────────────────────────────────────────────────────────────┘
```

## 🚀 Quick Start

### Prerequisites

- **Node.js** v18+ and npm
- **Python** 3.8+ and pip
- **MetaMask** browser extension (optional — for wallet signing)

### 1. Install Dependencies

```bash
# Smart contract dependencies
npm install

# Python edge agent dependencies
cd edge-agent
pip install -r requirements.txt
cd ..
```

### 2. Start Local Blockchain

```bash
npx hardhat node
```

This starts a local Ethereum node at `http://127.0.0.1:8545` with test accounts.

### 3. Deploy the Smart Contract

Open a **new terminal**:

```bash
npx hardhat run scripts/deploy.js --network localhost
```

This will:
- Deploy the `ThreatRegistry` contract
- Register a sample test threat
- Save the contract address and ABI to `edge-agent/config.json` and `frontend/deployment.json`

### 4. Launch the SOC Dashboard

Open `frontend/index.html` in your browser (or use a local server):

```bash
# Simple way — just open in browser
start frontend/index.html

# Or use a local server
npx -y serve frontend
```

Click **"Connect Wallet"** to connect to the local Hardhat node.

### 5. Start the Python Edge Agent

Open a **new terminal**:

```bash
cd edge-agent
python threat_guard.py --watch-dir ./test-files
```

The agent will monitor the `test-files` directory for any new files.

### 6. Demo — Test Threat Detection

1. **In the SOC Dashboard**: Register a new threat hash
2. **In a terminal**: Create a test file that produces that same hash in the monitored directory
3. **Watch the Python agent**: It will detect the file, query the blockchain, and quarantine it
